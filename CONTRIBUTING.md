# Contributing

1. Create a branch from `main`.
2. Keep changes focused and include tests for behavior changes.
3. Run `pnpm check`.
4. Open a pull request describing the user-visible result and security implications.

Node.js 24+ and pnpm 10.27+ are required. Never commit `data/`, `.env`, generated credentials, or backup snapshots. Contributions are licensed under AGPL-3.0-only.
